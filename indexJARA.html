Regret table

Regret = best payoff in that state (among all original alternatives) − the alternative's payoff.

How is each criterion calculated?

Maximax (optimistic): find each alternative's maximum payoff and pick the highest. Maximin (pessimistic): find each alternative's minimum payoff and pick the highest. Minimax Regret: find each alternative's largest regret and pick the lowest. EMV / Bayes: multiply each payoff by its state's probability, add them up and pick the highest expected value.
